\# 📊 Recruitment Candidate Tracker \& Hiring Dashboard



An interactive \*\*Recruitment Candidate Tracker \& Hiring Dashboard\*\* built using Microsoft Excel to track candidates, monitor recruitment progress, and analyze hiring data.



\## 📸 Dashboard Preview



!\[Recruitment Candidate Tracker Dashboard](screenshots/dashboard.png)



\## 🎯 Project Objective



The objective of this project is to create an interactive recruitment dashboard that helps recruiters and hiring teams monitor candidate information and recruitment progress in a simple and visual way.



The dashboard can be used to:



\* Track candidates throughout the recruitment process

\* Monitor candidate hiring status

\* Analyze recruitment data

\* Identify recruitment trends

\* Monitor key recruitment metrics

\* Make data-driven hiring decisions

\## 📌 Key Features



\### Candidate Tracking



Tracks important candidate information and recruitment details in a structured format.



\### Recruitment Status



Allows candidates to be monitored according to their current recruitment stage/status.



\### Interactive Dashboard



Provides a visual summary of recruitment information using charts, tables, and KPIs.



\### Data Validation



Uses Excel drop-down lists to maintain consistent candidate information and reduce data-entry errors.



\### Conditional Formatting



Highlights important candidate information and recruitment statuses for quick identification.
